全局快捷键使用指南

全局快捷功能

Space (空格键) ：随时切换“简约沉浸模式”，隐藏所有桌面元素。
/ (斜杠) ：快速呼出或隐藏顶部搜索框。
Esc + 1~9 ：无缝盲切前 9 个默认搜索引擎前缀。
Esc + 0 ：瞬间开启 / 关闭无痕搜索模式。

搜索与输入

Alt + Enter ：在搜索框输入中文后，一键将其翻译为英文搜索。
Ctrl + Enter ：在搜索框强力唤出高级搜索语法构建器。
Tab ：极速唤醒智能语音输入转文字。
Tab + 1~9 ：呼出智能联想词后，快速命中对应的项目。
Shift + Delete ：选中某条不想留存的历史记录时，彻底将其删除。

桌面空间导航

↑ ↓ ← → (方向键) ：丢掉鼠标，利用 2D 空间导航系统选择分类和磁贴。
Enter (回车) ：打开当前被键盘光晕高亮选中的磁贴或侧边栏分类。

生产力工具

Ctrl + V ：在展开的“翻译 / OCR”虚线框内，可直接粘贴系统剪贴板中的图片读取。
部分附带下划线的快捷键可以在设置中自由修改按键映射。
