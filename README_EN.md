## 🎨 Philosophy

> As a cross-disciplinary photographer stepping into the world of programming with the help of AI, I embarked on this development journey to build the ultimate new tab experience.
> 
> Drawing inspiration from the core mechanics of iTab, I integrated an array of practical, geek-oriented features. Driven by a strict eye for spatial composition and shadow logic, this project adopts a "Liquid Glass" design language. Through delicate Gaussian blur depths and layered shadows, it aims to create a highly responsive, emotional digital desktop.

## ✨ Key Features

### 🌪️ Visuals & Particle Engine
- **Dynamic Weather Simulation**: Real-time satellite data integration mapped to a built-in physics particle engine, rendering ultra-realistic rain, snow, and mist effects.
- **Liquid Glass UI**: Global 40px Gaussian blur with deeply layered shadows and silky-smooth iOS-style interface transitions. Supports time-synced Aurora ambient lighting.

### 🛠️ Productivity Tools
- **14-Engine Matrix**: A seamlessly integrated search hub featuring Google, Bing, ChatGPT, GitHub, Bilibili, and more, complete with fluid hotkey switching.
- **Precision Timing System**: Includes a Pomodoro timer, countdowns, and absolute-time alarms triggered with second-level precision.
- **Translation & OCR**: Built-in multi-engine translation and on-the-fly OCR text recognition.

### ☁️ Data & Sync
- **Java Backend Linkage**: Native support for connecting to local Java environments (`127.0.0.1:8080`) for secure cloud backup and state synchronization.
- **Smart Power Saving**: Hardware-aware battery monitoring. Automatically degrades particle rendering and enters power-saving mode when your device is unplugged.

### 🚀 Geek Hotkeys
- `/` **Quick Focus**: Press the `/` key anywhere on the page, and your cursor will instantly snap to the search bar.
- `Alt + Enter` **Smart Translation Search**: After typing your query, press this combo to automatically translate the text into English, drastically boosting international search efficiency.

## 📦 Installation & Usage

> Current Version: **3.8.5 (Stable)**

1. **Download**: Download the ZIP package from this repository and extract it.
2. **Load Extension**: Navigate to `chrome://extensions/` in your Chrome address bar, toggle on **"Developer mode"** in the top right, click **"Load unpacked,"** and select your extracted folder.
