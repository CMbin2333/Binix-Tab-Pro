## Key Features

### Visuals & Particle Engine

- **Dynamic Weather Simulation**: Real-time satellite data drives a built-in physics particle engine, rendering realistic rain, snow, and mist effects.
- **Liquid Glass UI**: Global 40px Gaussian blur with deeply layered shadows and smooth interface transitions. Supports time-synced Aurora ambient lighting.

### Productivity Tools

- **14-Engine Search Matrix**: A seamlessly integrated search hub featuring Google, Bing, ChatGPT, GitHub, Bilibili, and more, with fluid hotkey switching.
- **Precision Timing System**: Pomodoro timer, countdowns, and absolute-time alarms triggered with second-level precision.
- **Translation & OCR**: Built-in multi-engine translation and on-the-fly OCR text recognition.

### Data & Sync

- **Java Backend Linkage**: Native support for connecting to a local Java service (`127.0.0.1:8080`) for cloud backup and state synchronization.
- **Smart Power Saving**: Hardware-aware battery monitoring that automatically degrades particle rendering and enables power-saving mode when your device is unplugged.

### Geek Hotkeys

| Shortcut | Function |
|----------|----------|
| `/` | **Quick Focus**: Press `/` anywhere on the page to instantly snap the cursor to the search bar. |
| `Alt + Enter` | **Smart Translation Search**: After typing your query, press this combo to auto-translate the text into English, drastically boosting international search efficiency. |

## Installation & Usage

> Current Version: **3.8.5 (Stable)**

1. **Download**: Download the ZIP package from this repository and extract it.
2. **Load Extension**: Navigate to `chrome://extensions/` in your Chrome address bar, toggle on **"Developer mode"** in the top right, click **"Load unpacked"**, and select your extracted folder.
