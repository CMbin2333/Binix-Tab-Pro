## ✨ 核心功能

### 🌪️ 视觉与特效
- **动态气象模拟**：实时调用卫星数据，内置物理粒子引擎，可渲染逼真的雨滴、雪花或迷雾效果。
- **液体玻璃 UI**：全局 40px 高斯模糊与分层阴影，支持随时间变化的极光主题色。

### 🛠️ 效率工具
- **14 种引擎矩阵**：集成 Google, Bing, ChatGPT, GitHub, Bilibili 等引擎，支持快捷键切换。
- **精确计时系统**：包含番茄钟、倒计时及绝对时间闹钟，精确到秒级触发。
- **翻译与 OCR**：内置多引擎翻译与 OCR 文字识别工具。

### ☁️ 数据与同步
- **Java 后端联动**：支持接入本地 Java 服务 (`127.0.0.1:8080`) 实现云端备份同步。
- **智能省电**：感知电池状态，断电自动开启省电模式以优化续航。

### 🚀 极客快捷键
- ` / ` **快速聚焦**：在网页任何位置按下 `/` 键，鼠标光标将自动跳转并聚焦至搜索栏。
- `Alt + Enter` **智能翻译搜索**：在搜索框输入内容后，按此快捷键可将当前文字自动翻译为英语，极大提升国际化搜索效率。

## 📦 安装与使用

> 当前版本：**3.0.0 正式版（稳定）**

1. **下载代码**：下载本仓库 ZIP 包并解压。
2. **载入扩展**：在 Chrome 的地址栏输入 `chrome://extensions/`，开启右上角的“开发者模式”，点击“加载解压的扩展程序”，选择解压后的文件夹即可。
